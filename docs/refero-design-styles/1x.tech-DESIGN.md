# 1X — domestic cinematic engineering

## Overview

Human warmth meets advanced engineering in an image-led, predominantly light visual world. Soft off-white canvases, warm charcoal typography and tiny orange markings frame natural photography, tactile product studies and cinematic demonstrations. An understated grotesk and unusually small opening titles let the product and its relationship with people carry the emotion. The sparse density suits ambitious physical products and technical platforms that want to feel at home in ordinary life.

### Essentials

- The opening is a portrait, not a typographic billboard: edge-to-edge media fills a 900px desktop screen, with a low-centered 24px bold product name, 24px regular category and a white pill action above an 80px bottom clearance.
- Capability chapters feel like film intertitles: centered 56px/1.2 medium headings, 24px/1.3 support within 640px, 16px between text levels and 80px before the next large media stage.
- Engineering is softened by enormous corners: 1280×720 demonstrations use 80px radii; the material carousel enlarges a 720px square center image between 475px side previews. Include tactile close-ups, or equally close photographic studies of the new product's materials and interactions.
- Controls are small capsules over an expansive scene: 9999px action radii, a 53px white opening button, charcoal filled closing actions and translucent black media labels with 24px backdrop blur.
- Color belongs mostly to the world being photographed: the interface stays off-white and charcoal; #ff5c00 is restricted to 11px uppercase chapter markings with 0.2em tracking and occasional 16px status dots, never broad panels.
- A pale product sculpture resolves the story: a large isolated object fades into the #f7f7f7 canvas below a compact identity and action cluster. Include this object-led release of visual tension; for intangible products use a carefully art-directed physical metaphor or a clean isolated product artifact, not a dashboard collage.

## Layout

**Density:** Airy: cinematic panels occupy most of the document while the text is limited to short, separated clusters.

### Spacing

**Spacing system:**

- **grid** 8px — Dominant spacing rhythm for section offsets, gutters and text gaps; compact capsule padding has deliberate exceptions.

| Value | Use |
| --- | --- |
| 8px | Tight identity/category separation and dot gaps. |
| 16px | Heading/support separation, action-pair gap and feature icon-to-copy gap. |
| 24px | Control horizontal padding and footer link-column vertical rhythm. |
| 32px | Global side inset, footer padding and common grid gaps. |
| 40px | Carousel-to-pagination gap and editorial row padding; declared gutter. |
| 56px | Narrow-layout section spacing and compact product navigation height. |
| 80px | Desktop section spacing, demonstration side insets and feature-column gaps. |

### Containers and grids

- **cinema**: max width 1440px · side padding 0px. Full-bleed opening portrait and occasional immersive demonstration.
- **demonstration**: max width 1440px · side padding 80px. Centered 1280px-wide demonstration inside the desktop canvas.
- **chapter-copy**: max width 720px · side padding 32px. Centered heading group; support is limited further to 640px.
- **feature-row**: 3 columns · gap 80px · side padding 32px. Centered unboxed benefit items, each limited to 266px; a four-column variant explains construction.
- **product-navigation**: max width 855px · side padding 24px. Compact persistent rail centered inside a full-width band.
- **editorial-row** (only for technical update stories): max width 1360px · 2 columns · gap 40px · side padding 40px. 752px media beside a narrower centered text group.
- **support-split** (only for editorial support sections): max width 1184px · 2 columns · gap 32px · side padding 80px. 1024px inner span for a text column beside 506×626px portrait media; also used by subscription closing bands.
- **chronology** (only for company chronology): 2 columns · gap 0px. Equal 720px halves: a held product figure on the left and 880px-tall photographic chapters on the right.

## Surfaces and depth

### Surfaces

#### Frost canvas · level 0

**Use:** Default continuous page ground.

**CSS:** `background: #f7f7f7; color: rgba(0, 0, 0, 0.72)`

**Observed:** Text and media sit directly on one uninterrupted pale field, with no raised white-card system.

**Transfer:** Let whitespace separate chapters.

#### Dark glass · level 2

**Use:** Readable controls and labels over moving or detailed imagery.

**CSS:** `background: rgba(0, 0, 0, 0.44); backdrop-filter: blur(24px); border-radius: 9999px; color: #ffffff`

**Observed:** Scene color remains visible through the capsule; no drop shadow or glowing outline.

**Transfer:** Use only where a label actually overlaps a picture.

#### Light navigation veil · level 2

**Use:** Persistent global navigation after the opening media.

**CSS:** `background: rgba(247, 247, 247, 0.824); border-bottom: 1px solid rgba(79, 71, 73, 0.043)`

**Observed:** A thin translucent band separates navigation from content; over the opening it becomes visually transparent with light text.

**Transfer:** Switch contrast with the underlying scene, without introducing a dark menu slab.

#### Fading chapter rule · level 0

**Use:** Subtle separation before a new capability theme.

**CSS:** `background: linear-gradient(90deg, rgba(0, 0, 0, 0), rgba(0, 0, 0, 0.086) 49.52%, rgba(0, 0, 0, 0)); height: 1px; max-width: 640px`

**Observed:** Centered hairline disappears toward both ends.

**Transfer:** Use sparingly instead of full-width strong dividers.

#### Editorial frost · level 0

**Only for:** editorial, company and production stories

**Use:** Long-form editorial ground.

**CSS:** `background: #f8f8f8`

**Observed:** Almost the same tone as the footer and navigation, with only subtle seams.

**Transfer:** Preserve a continuous light world rather than alternating many panel colors.

#### Quote wash · level 1

**Only for:** testimonials

**Use:** Soft grouping for human quotations.

**CSS:** `background: rgba(65, 62, 62, 0.04); border-radius: 40px; box-shadow: none`

**Observed:** A barely gray wash on the editorial canvas rather than an outlined card.

**Transfer:** Keep the quote as the main visual mass and attribution low in the panel.

## Components

### Global navigation

**Use:** Top-level site orientation.

**CSS:** `height: 60px; padding: 0px 32px; position: fixed; width: 100%; display: flex; align-items: center; justify-content: space-between`

**Text style:** `navigation` — ABCDiatype 500 · 11px/20px · tracking 0.08em · uppercase

**Observed:** Small mark at far left, centered category links spaced 50px apart and a conversion link at far right. White lettering sits over the opening picture; the Light navigation veil supports dark lettering later.

**States:** Declared: hover opacity 1 on navigation links.

**Transfer:** Keep the center group short and the edge action visually modest.

### Product navigation

**Use:** Persistent orientation within a long product story.

**CSS:** `background: #f7f7f7; max-width: 855px; padding: 12px 24px; display: flex; align-items: center; justify-content: space-between`

## Imagery and graphics

### Human product portrait

**Use:** Opening signature image.

**Observed:** A large waist-up product and person share the frame against a mottled blue-gray studio wall. Soft, broad light reveals skin, gray knitwear and fine textile texture. The person looks toward the product with an unforced gesture; subjects fill almost the entire viewport and continue off the lower edge.

**Transfer:** Photograph the new product with a person at natural scale and a gentle interaction. If a shoot is unavailable, use one believable contextual photograph with similar soft light and visible materials; do not replace it with a collage of stock faces.

### Domestic cinema

**Use:** Large demonstrations between short capability chapters.

**Observed:** Warm wood, cream walls, green plants, ordinary furniture and daylight create lived-in rooms. Videos are framed like observational films rather than promotional graphics; wide views show a complete interaction, followed by tighter product details. Most are inset within huge rounded rectangles.

**Transfer:** Show the equivalent product doing something understandable in a credible environment. For software, film the human context and a legible focused interaction rather than filling the entire page with a busy interface.

### Tactile mechanism studies

**Use:** Signature detail carousel and construction chapter.

**Observed:** Cream lattice cushioning, tendon-like cables, satin metal joints, woven fabric and a blue-gray face against dry rust-colored leaves. Macro focus alternates engineered structure with soft natural material; muted photographic color supplies the richness absent from the interface.

**Transfer:** Use closely framed photographs of your product's actual textures, internal craft and nature-adjacent context. The minimum is three consistently lit detail images with genuinely different material information.

### Frost product sculpture

**Use:** Closing conversion and product-directory opening variant.

**Observed:** An isolated ivory product in profile rises from a pale field; lower edges dissolve softly into the surrounding canvas. The closing figure occupies an 1100×753px image stage below a compact action group, without a frame or shadowed card.

**Transfer:** Create a high-resolution isolated product render or photograph with matching pale lighting and broad empty margins. For an intangible offer, use one restrained artifact or physical metaphor that can hold this sculptural role.

**Build:** Place a softly lit transparent-background object centered on #f7f7f7. Overlay a bottom-aligned linear gradient from rgba(247,247,247,0) to rgba(247,247,247,1) across the bottom portion so the object melts into the canvas. Keep its silhouette crisp above the fade and avoid a hard rectangular image boundary.

### Isometric process world

**Only for:** production and process explainers

**Use:** Technical proof that needs spatial explanation.

**Observed:** A fine gray isometric line rendering shows a cutaway facility, racks, vehicles and tiny human figures. The scene spans the width under a centered heading; its perimeter fades into the light canvas while a capsule selector and annotation remain crisp.

**Transfer:** Draw the new product's process as a simplified spatial system, not a decorative network diagram.

**Build:** Use SVG isometric parallel lines for floor planes and equipment boxes, mostly unfilled with fine gray strokes and occasional low-opacity gray faces. Layer a radial-gradient(rgba(0,0,0,0) 20%, #f8f8f8 70%) over the wide scene. Put a compact annotation at the lower center and a segmented selector beneath the heading.

### Editorial evidence media

**Only for:** technical updates and recruitment stories

**Use:** Paired story rows and tall support panels.

**Observed:** Rounded media shows retro television installations, monochrome technical visualization, forest environments and close-ups of hands assembling machinery. A wide image carries most of a technical update row, while tall 506×626px pictures balance sparse editorial text.

**Transfer:** Use authored images of the product's real research, making and working context. Keep saturated diagnostic colors inside demonstrations rather than promoting them into site accents.

### Chronology diptych

**Only for:** company chronology

**Use:** Long-form evolution narrative.

**Observed:** A clean isolated full-length product remains centered on the left pale half while the right half scrolls through drawings, macro mechanisms and domestic films. Each right panel is 720×880px with tiny date/title/copy overlays near its lower portion; white overlays gain subtle dark gradients when needed.

**Transfer:** Hold the evolving artifact on one side and tell its history through documentary material on the other; maintain the calm contrast between isolated object and full-bleed evidence.

### Icons

**Observed:** Small functional chevrons, solid play triangles and reading symbols; feature pictograms are about 32px, while media chevrons can be only 8×15px with 2px round strokes. Icons inherit light or charcoal foreground and sit inside capsules or above feature copy.

**Transfer:** Use a consistent simple pictogram set; keep media controls small and avoid decorative colored icon tiles.

## Section recipes

How recurring sections are built.

### First screen: Portrait opening

**Observed:** A full 1440×900px edge-to-edge portrait forms the back layer, with the product on one side and a person on the other; both are large enough to extend beyond the bottom edge. Global navigation floats at the top. Near the lower center, the 24px bold Product-identity sits above the 24px regular category, followed by the Hero button and a 14px term line, with 16px gaps between the principal groups and 80px clearance below. All of that is visible in the first 900px; no benefit heading or next-section teaser intrudes. The tiny white title is intentionally subordinate to faces and tactile surfaces.

**Transfer:** Keep this portrait-led composition for a new product landing page, photographing a credible use relationship rather than adding a large slogan. A carefully lit contextual still is sufficient when film is unavailable. Editorial pages instead use the Editorial-opening recipe aligned to the left at mid-height over full-bleed media; a directory can use isolated products on a pale field.

**Avoid:** Do not make the opening a 50/50 text-and-render split, enlarge the title to billboard scale, or place opaque gradient cards behind the identity.

**Text style:** `product-identity` — ABCDiatype 700 · 24px/1.3

### Capability chapter

**Observed:** Centered 11px orange Eyebrow, 56px Heading and 24px Lead use 16px gaps. Support occupies at most 640px. An 80px pause leads into a 1280×720px demonstration with 80px corners and 80px side insets. Feature items can follow in three or four unboxed columns.

**Transfer:** Give each capability one human benefit and one visually understandable demonstration.

**Text style:** `heading` — ABCDiatype 500 · 56px/1.2

### Immersive example

**Observed:** A full-width demonstration leaves the contained frame behind. A Media selector sits near the upper center; white heading/support can occupy a darker lower area using a soft black bottom fade and blurred transition at the scene edge.

**Transfer:** Reserve this expansion for an interaction that benefits from immersion rather than using it for every chapter.

### Tactile carousel

**Observed:** Material carousel creates a deliberately oversized center square with smaller clipped previews at both edges. Caption pills stay attached to the imagery, and a quiet dot row occupies the space below.

**Transfer:** Use the device to communicate physical quality, construction or meaningful detail, not a generic gallery of promotional banners.

### Sculptural conversion

**Observed:** 80px top and bottom spacing surrounds a centered 24px product identity and category. Outlined button and Dark button sit 16px apart, then a 14px term line. After 40px comes the large Frost product sculpture, dissolving into the pale canvas before Footer columns.

**Transfer:** Resolve the page with the product itself and a clear next step rather than another persuasive paragraph.

**Text style:** `product-identity` — ABCDiatype 700 · 24px/1.3

### Technical update row

**Only for:** technical update stories

**Observed:** Within a 1360px row padded 40px, a 752×515px image with 48px corners sits left of centered copy. A small outlined topic capsule and tracked date precede a 44px Editorial-heading; 20px/1.5 Editorial-body sits within 392px below it. Watch/read glass actions overlap the lower image edge.

**Transfer:** Repeat for product releases or technical progress, keeping metadata small and the actual proof visually dominant.

**Text style:** `editorial-heading` — ABCDiatype 500 · 44px/1.2

### Spatial proof and human proof

**Only for:** production and process stories

**Observed:** A centered 56px heading introduces a short capacity statement, a small segmented location selector and the Isometric process world. Documentary videos and a three-card Quote-card row provide human contrast to technical explanation.

**Transfer:** Use a factual process or capacity statement only when it can be supported; pair technical scale with specific people and craft.

### Editorial split support

**Only for:** editorial support sections

**Observed:** A 1024px inner span balances a sparse left text group with a 506×626px right image using 48px corners. A 30px Secondary-heading leads article or recruitment content; subdued metadata sits beneath each short list entry.

**Transfer:** Use for related resources, real opportunities or deeper reading without converting it into a dense card grid.

**Text style:** `secondary-heading` — ABCDiatype 400 · 30px/1.3 · tracking -0.03em

### Held artifact chronology

**Only for:** company chronology

**Observed:** Equal-width halves place an isolated evolving object at left against the continuous pale canvas and a vertical succession of 880px photographic panels at right. Milestone copy stays narrow at 320px, using 12px dates/body and 18px titles. The final right panel replaces imagery with a centered subscription cluster while the left object remains present.

**Transfer:** Adapt to a product evolution, craft history or research journey; retain the unequal visual density of the two halves.

**Text style:** `timeline-heading` — ABCDiatype 400 · 18px/1.6

### Underlined closing invitation

**Only for:** editorial and directory endings

**Observed:** A compact two-part 30px invitation sits opposite an Underlined email form within the 1024px editorial span; secondary words are subdued. Small reassurance follows under the form. A directory variant places the invitation over full-screen muted video with 44px pale text; the chronology variant holds it within the right half of a tall split panel. Every version leads into the pale Footer columns.

**Transfer:** Use a low-pressure invitation when direct ordering is inappropriate; keep the action visually quieter than the preceding media.

**Text style:** `secondary-heading` — ABCDiatype 400 · 30px/1.3 · tracking -0.03em

## Page flow

**Storyline:** Human context → practical benefit → observed capabilities → tactile or technical proof → future potential → focused invitation → recessive utility footer.

### Image-led product and brand directory

1. **Product promise** — A full-screen pale product lineup with compact paired title and small conversion action.
2. **Human context** — A second full-screen portrait introduces participation or opportunity.
3. **Closing invitation** — Full-screen muted film carries a paired invitation and underlined email form.
4. **Utility ending** — Pale shared footer with small mark and four link columns.

**Transfer:** Use a few full-screen editorial destinations when breadth matters more than detailed capability explanation.

### Flagship product landing page and default visual grammar

1. **Human promise** — Full-screen relationship portrait with low-centered product identity and white action.
2. **Practical benefits** — Large centered benefit statement, domestic demonstration and unboxed feature row.
3. **Capability chapters** — Orange markings introduce short headings and expansive demonstrations; the product navigation provides chapter access.
4. **Material proof** — Construction film, small feature explanations and the enlarged detail carousel.
5. **Long-term potential** — Further conversational and future-capability demonstrations on the same pale canvas.
6. **Closing conversion** — Compact paired actions above a fading isolated product sculpture, then the shared light footer.

**Transfer:** Let real use scenes carry the claim; balance large demonstrations with extremely economical text.

### Technical progress and research communication

1. **Human context** — Full-screen contextual image with a left-aligned compact title.
2. **Progress marker** — Tiny orange dot introduces the update stream.
3. **Technical proof** — Repeated media-heavy rows pair topic/date, narrow headings and explanatory text; occasional wide demonstrations interrupt the rhythm.
4. **Participation** — Sparse opportunity list beside tall contextual photography.
5. **Closing invitation** — Underlined email form and short invitation precede the shared pale footer.

**Transfer:** Organize updates by demonstrable progress, separating editorial narrative from diagnostic media colors.

### Explain making, scale and organizational capability

1. **Human promise** — Full-screen documentary film with a play-mark title capsule.
2. **Quantified proof** — Capacity statement and location controls above a fading isometric process model.
3. **Process demonstration** — Wide documentary examples with floating capsule selectors.
4. **Human proof** — Short quotes with portrait attributions bridge technical and personal credibility.
5. **Deeper engagement** — Article teaser and opportunity list use tall documentary photographs.
6. **Closing invitation** — Quiet underlined subscription band and shared pale footer.

**Transfer:** Explain an authentic production or service process, combining spatial clarity, factual scale and human experience.

### Company or product evolution story

1. **Context** — Full-screen contextual film, then a two-column mission introduction.
2. **Evolution proof** — A held isolated product on the left evolves alongside chronological images and small milestone overlays at right.
3. **Forward invitation** — The last right-hand panel becomes a centered waitlist form while the isolated object remains on the left.
4. **Utility ending** — Shared pale footer closes both columns.

**Transfer:** Use sustained visual comparison to show meaningful development rather than an ornamental date list.

## Writing

Calm, optimistic and concrete. Technical ambition is expressed through understandable actions and ordinary benefits, with warmth supplied by situations and people rather than exuberant adjectives.

**Do not copy:** Do not reuse the 1X or NEO names, logos, proprietary model names, robot likenesses, deposit amount, capacity figures, role counts, dates, employee quotations or unverified autonomy and safety claims. Examples below illustrate language structure only.

- **Addressing the reader:** Use you and your for reader benefits; refer to the product by name for capability explanations. We appears in company-history passages, not as a constant sales narrator.
- **Rhythm:** Headlines are usually two to five words. Support is one direct sentence or two short sentences; technical update paragraphs can be longer when they explain a real mechanism. Actions are one or two words; reassurance is plain and brief.

| Role | Pattern | Typical length | Examples of the pattern |
| --- | --- | --- | --- |
| Opening identity | Product name followed by a literal category, not a campaign slogan. | One name plus two category words | “NEO”<br>“Home Robot” |
| Benefit heading | Active verb plus a familiar human outcome; title case. | 2–4 words | “Transform Your Home”<br>“Laugh and Learn”<br>“Grows With You” |
| Capability support | State what the product does and connect it to what the reader gains. | One sentence, about 20–35 words | “NEO takes on the boring and mundane tasks around the house so you can focus on what matters to you.” |
| Technical headline | Name the progress plainly rather than claiming a revolution. | 1–4 words | “Learning New Abilities”<br>“Evaluation” |
| Action | Literal next step using a short verb phrase. | 1–2 words | “Order Now”<br>“Watch Video”<br>“Read Article” |
| Form reassurance | Brief consent and reversibility statement. | Two short sentences | “Opt in to receive updates. Unsubscribe anytime.” |

**Words and phrasing to use:** help; learn; home; everyday; built; gentle; works; abilities; with you

**Avoid:** disruptive; game-changing; unleash; supercharge; magic; revolutionary ecosystem

**Rules:**

- Lead with the useful action; explain machinery only when it makes that action more credible.
- Keep limitations and access conditions explicit rather than hiding them behind aspirational language.
- Use specific demonstrations instead of stacks of adjectives.
- Let short title-case headings alternate with sentence-case explanatory text.

## Do's and Don'ts

### Do

- Keep the opening product name at 24px even when the image fills the screen.
- Use 56px medium centered chapter headings with normal tracking and 16px text-level gaps.
- Give 1280×720px demonstrations 80px desktop corners and 80px side space.
- Place short 11px orange uppercase markers above capability headings.
- Use 9999px capsules for actions and overlapping media captions.
- Keep feature descriptions unboxed in 266px columns with 80px gaps.
- Resolve a product story with an isolated fading object and compact action cluster.
- Keep the footer pale, with 32px padding and four small link columns on its right half.

### Don't

- Do not turn the interface into a black technical dashboard; #222222 is media backing, not the main canvas.
- Do not use orange as a button fill or broad section background; it is a micro-label accent.
- Do not introduce elevated white feature cards with drop shadows; the primary layout is continuous frost.
- Do not apply negative tracking to every heading; the 56px chapter recipe uses normal tracking.
- Do not use 8px card corners for large demonstrations; the default desktop media radius is 80px.
- Do not put a filled rounded input box around the newsletter field; its structure is one 1px underline.
- Do not make the footer a promotional billboard or reverse it into a dark band.
- Do not let diagnostic neon colors escape from technical demonstration imagery into the marketing palette.

## Motion and responsive

### Motion

**Observed:**

- Declared: navigation opacity transitions use 0.2s cubic-bezier(0.4, 0, 0.2, 1).
- Declared: hero and closing action color transitions use 0.15s cubic-bezier(0.4, 0, 0.2, 1).
- Declared: global header transitions use all 0.3s cubic-bezier(0.4, 0, 0.2, 1).
- The product rail remains available through the long chapter sequence; media selectors and pagination identify the active demonstration.

**Transfer:**

- Use small opacity/color changes for capsules rather than lifting cards or adding shadows.
- Keep a product-specific chapter rail during extended media storytelling; maintain readable controls while scenes change.

**Unknown:**

- Exact scroll-trigger timing, carousel travel duration, video playback rules and focus-visible treatments are not established.

### Responsive

**Observed:**

- Declared component classes switch section spacing from 56px to 80px and demonstration radii from 48px to 80px at larger layouts.
- Global navigation declares a compact 52px height with 20px side padding, versus 60px and 32px at desktop.
- Feature items declare a narrow-layout row arrangement and a wider-layout centered column arrangement.

**Transfer:**

- On narrow layouts, preserve the portrait-led opening and low-centered identity while protecting faces and the main product silhouette.
- Stack feature groups and editorial split content; retain the distinction between isolated object studies and documentary imagery.
- Keep oversized carousel previews visibly clipped rather than shrinking every image into a tiny equal-size grid.

**Unknown:**

- Exact mobile image choices, menu behavior and breakpoint-specific type sizes are not established.

## How to use this guide

1. Start from the Essentials and the first-screen recipe; where the guide offers variants, use the default named for a new marketing page.
2. Plan the page before building: map your content onto the section recipes and page flow, then check the plan against the Do's and Don'ts.
3. Build with the tokens and component specs; recreate signature graphics with their build recipes instead of generic decoration, and use the named font substitutes if a font is unavailable.
4. Render the page at desktop and mobile widths, compare it with the Essentials and the Don'ts, and fix the differences before you finish.
